## Impact

- No defect changes physics, rewards used for training, resets, observations, success logic or selection.
  The v1 tables and conclusions stand as published, with the corrected labels (E1).
- E2 affects one logged field only. v2 records carry the full return; v1 raw records are unchanged.
- E3 (interpretation): the v1 step-0 policies are geometry plus a seed-specific constant offset, not a zero
  residual (Stage 2). v2 uses a zero-mean initialization so the untrained control equals geometry exactly.
- v2 does not mix corrected and original runs: all v2 comparisons use v2 records only; v1 results are cited
  as v1.
