# Closeout errata (corrections made for release v2.1.0)

These corrections change wording, provenance and the reproduction workflow. **No v1 or v2 number changes.**
All v2 summaries were regenerated byte for byte from the downloaded v2.0.0 raw records. Archived assets of
v1.0.0 and v2.0.0 are not modified: the v2.0.0 documents are kept byte-identical in the v2.0.0 release and in
`v2.0.0-originals.tar.gz` of v2.1.0. Earlier v1 errata (E1–E3) are in [docs/v2/V1_ERRATA.md](../v2/V1_ERRATA.md).
